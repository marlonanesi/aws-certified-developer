Curso completo em **português brasileiro** preparatório para a certificação **AWS Certified Developer - Associate (DVA-C02)**.

> **💡 Sobre os roteiros de lab**
> Os roteiros práticos (`roteiro.md`) incluem os comandos nos dois principais ambientes:
> 🪟 **PowerShell** (Windows) e 🐧 **Bash** (Linux/macOS), para facilitar a execução independentemente do sistema operacional.
> Caso utilize outro ambiente, é possível usar uma ferramenta de **GenAI** (como o próprio GitHub Copilot) para converter os comandos para o formato desejado. 🤖

## 📁 Organização do Curso

Cada seção do curso segue uma estrutura padrão com duas pastas principais:

```
secao_N_nome_do_tema/
├── aulas/          # 🎓 Aulas teóricas em PDF
└── anexos/         # 🧪 Materiais de apoio dos labs
    ├── lab1/
    │   ├── roteiro.md      # 📋 Passo a passo do lab
    │   └── *.py / *.yaml   # 💻 Código e configs do lab
    ├── lab2/
    └── ...
```

> **Exemplo — Seção 3: AWS Lambda**
>
> ```
> secao_3_aws_lambda_computacao_serverless/
> ├── aulas/
> │   ├── Aula_1_Lambda_Intro.pdf
> │   ├── Aula_2_Lambda_Anatomia.pdf
> │   └── ...
> └── anexos/
>     ├── lab1/
>     │   ├── roteiro.md
>     │   └── lambda_handler.py
>     ├── lab2/
>     │   ├── roteiro.md
>     │   └── lambda_config.py
>     └── ...
> ```
